git init: Initialize Git VCS locally 
git add: stage the changes
git rm - - cached <filename>: unstage the changes
git config: used to set identity for making commits, this identity is used to maintain history of commits.
git commit:  commit the changes into Git VCS
git reset: undo only local commit 
git reset --soft HEAD~1: removes last commit and delete changes
git reset --hard HEAD~1: removes last commit and delete changes
git log: shows the history of commits 
git config  - - list: shows set identity
git status: shows current status of repo 
git show: shows the changes made
git branch: check current branch 
git branch -m: rename branch 
git log –oneline: shows all commits in oneline each
