### Understand the Anatomy
- on: It initiates the event which needs to trigger to start the workflow.
- jobs: Defines the job in the workflow like need to be done.
- runs-on: It selects OS on which job gonna be executed.
- steps: Task inside the job which need to be taken to complete the job.
- uses: Tells github which existing action to be used.
- run: It runs linux command inside the workflow
- name: It defines the name of the step
