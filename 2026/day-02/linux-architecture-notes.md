2. ## What Systemd does ?
   * systemd is a file manager which having PID=1 it initated by kernel and after that it starts all other process and manage them when to start, stop etc. process.

3. ## Process States:
   * S --> Process is sleeping and waiting for something to run.
   * R --> process is running on CPU
   * T --> process is stopped 
   * I --> process is idle
   * Z --> process in zoombie state

4. ## Top 5 commands commenly used on daily basis
   * These directories contains most of the commands: /bin, /sbin, /usr/bin, /usr/sbin / /usr/local/bin
   * cd --> used to navigate the directories
   * grep --> for searching specfic word in larage log files
   * pwd --> print current working directory
   * ps / top / htop --> shows all the running process
   * systemctl --> used to manage services such as start stop etc.
