## Include at least 20 commands with one‑line usage notes
- cat --> displays the log file
- grep --> search specifict string in the log file
- awk --> it applies input actions line by line in the log file
- sed --> used to edit or manipulate log files
- cut --> it extracts specific portion of file
- sort --> sorts the log in a sequence
- uniq --> filter out duplicate log entries which can be seen easily after sorting log
- wc --> count word in the log file
- head --> shows the top part of log file
- tail --> shows the last part of the log file
- less --> shows logs with less lines
- more --> shows logs with full length or  more lines
- zgrep --> search inside the compressed files
- tr --> translate specific word inside the log file
- find --> to locate the log files by name size or date etc
- kubectl logs --> displays kubernetes container logs for analysis
- journalctl logs --> it shows systemd logs
